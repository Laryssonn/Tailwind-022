🎨 Learning Tailwind CSS

This project was created to learn and practice Tailwind CSS by building a simple page and exploring different ways of using it.

The repository contains two versions of the project:

Vanilla — Tailwind CSS with HTML, CSS, and pure JavaScript.
Vite — Tailwind CSS with Vite and React.

The goal is to understand how Tailwind CSS can be used in both a simple vanilla JavaScript project and a modern React application.

🟦 Vanilla

The vanilla folder contains a version of the project built with pure JavaScript, without using any framework.

This version is focused on understanding how Tailwind CSS works in a simple web project using the fundamental web technologies.

Running the project

Navigate to the vanilla folder:

cd vanilla


Then open the index.html file in your browser.

You can also use a development extension such as Live Server.

⚛️ Vite + React

The vite folder contains a version of the project built with React and Vite.

This version focuses on using Tailwind CSS in a React application while also practicing component-based development.

Running the project

Navigate to the vite folder:

cd vite


Install the dependencies:

npm install


Start the development server:

npm run dev


Vite will then provide a local URL where the application can be accessed.
